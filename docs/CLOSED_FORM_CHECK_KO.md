# 제한 결측 임계값: 닫힌형 계산 검증

제공된 원고 캡처의 식과 0·1 경계 처리 조건을 기존 코드와 비교했습니다.
**경계까지 적용하면 결과는 같습니다.** 유한한 임계값 7개에서 기존 Brent
수치해와의 최대 절대 차이는 **7.9128 × 10⁻¹²**입니다. 나머지 1개인
중국·분할계수는 기존처럼 허용 범위 안에서 임계값이 없습니다.

코드의 임계값 계산을 닫힌형으로 바꾸고 S10b의 두 임계값 열을 새 값으로
갱신했습니다. 원고 표시 자리수의 숫자, 결측 경계 구간, 방향 식별 여부와
논문의 결론은 달라지지 않습니다.

## 기존 계산과 비교 범위

기존 `critical_delta`는 `scipy.optimize.brentq(..., xtol=1e-10)`로
결측 경계가 0에 처음 닿는 δ를 찾았습니다. 원고의 식과 동일한 0·1 절단
규칙을 이미 적용했지만, 임계값 자체는 반복 수치해법으로 구했습니다.

이번 변경은 **임계값 δ 계산에 한정**됩니다. S10에서 연도별 결측률을 복원하는
기존 `fsolve` 단계는 유지했습니다. 두 방법에는 동일한 입력을 사용했습니다.

- 2018년 결측률: 0.35338130632631404
- 2024년 결측률: 0.23207665362685420
- 국가군 4개 × 분자 계수법 2개: 총 8개 조합

기존 계산은 `source/EPJDS_v06_assets/build_restricted_missingness_bounds.py`에,
기존 CSV는 `provenance/baselines/table_s10b_brentq.csv`에 보존했습니다.

## 수식과 경계 처리

연도를 0=2018, 1=2024로 줄여 쓰고, a는 관측 채택비중, s는 관측 생산비중,
m은 생산량 분모의 국가결측률로 둡니다. 코드의 `r18`, `r24`가 원고의 m입니다.

$$
N=a_1s_0-a_0s_1,\qquad \sigma=\operatorname{sign}(N),
\qquad w_0=a_1m_0,\quad w_1=a_0m_1.
$$

변화가 양수이면 2018년 결측 국가비중은 내리고 2024년은 올리는 극단점이
차이를 가장 빠르게 0으로 이동시킵니다. 음수이면 방향을 반대로 합니다.
각 연도의 허용 이탈 거리는 다음과 같습니다.

$$
(b_0,b_1)=
\begin{cases}
(s_0,1-s_1), & N>0,\\
(1-s_0,s_1), & N<0.
\end{cases}
$$

따라서 실제 생산비중은

$$
\widetilde{s}_0=s_0-\sigma m_0\min(\delta,b_0),\qquad
\widetilde{s}_1=s_1+\sigma m_1\min(\delta,b_1)
$$

이며, 두 PRI가 같아지는 조건을 교차곱하면 다음의 구간별 일차식이 됩니다.

$$
|N|=w_0\min(\delta,b_0)+w_1\min(\delta,b_1).
$$

경계에 닿기 전에는 캡처에 표시된 식과 정확히 같습니다.

$$
\delta_{\mathrm{interior}}=\frac{|a_1s_0-a_0s_1|}{a_1m_0+a_0m_1}.
$$

다만 이 값이 `min(b0,b1)`을 넘으면 먼저 포화되는 항을 고정해야 합니다.
bL≤bH가 되도록 b와 해당 w를 함께 정렬하면, N≠0이고 관련 가중치가 양수일 때
최종 해는 다음과 같습니다.

$$
\delta^*=
\begin{cases}
\displaystyle\frac{|N|}{w_L+w_H},
 & |N|\le (w_L+w_H)b_L,\\[6pt]
\displaystyle\frac{|N|-w_Lb_L}{w_H},
 & (w_L+w_H)b_L<|N|\le w_Lb_L+w_Hb_H,\\[6pt]
\text{허용 범위 안에 임계값 없음},
 & |N|>w_Lb_L+w_Hb_H.
\end{cases}
$$

N=0이면 이미 방향이 식별되지 않으므로 임계값은 0입니다. 두 연도의 결측률이
모두 0이고 N≠0이면 임계값이 없습니다. 구현과 검사에는 가중치 하나가 0인 경우,
경계에서 정확히 같아지는 경우도 포함했습니다.

**경계 전 식만 모든 경우에 적용하면 다른 결과가 나옵니다.** 중국·완전계수의
경계 전 후보는 0.258094이지만 올바른 최종 임계값은 0.692940입니다.
인도·완전계수는 0.118000에서 경계 보정 후 0.152456이 됩니다.
중국·분할계수는 경계 전 후보 0.264984가 있어도 실제 허용 범위에는 임계값이
없습니다. 이는 원고 캡처에 적힌 경계 보정이 실제 계산에서 필요함을 보여줍니다.

## 수정된 자료와 검증

- `scripts/build_restricted_bounds.py`: 임계값을 구간별 닫힌형으로 계산합니다.
- `results/additional_files/table_s10b_restricted_missingness_bounds.csv`:
  72행 중 유한 임계값을 가진 63행의 `critical_delta`와
  `critical_delta_relative_to_share`를 갱신했습니다. 상대 임계값의 최대 차이도
  1.09 × 10⁻¹⁰ 수준입니다. 다른 열은 동일합니다.
- `results/qa/closed_form_comparison.csv`: 8개 조합의 경계 전 후보, 경계점,
  최종 해, 기존 값과의 차이를 제공합니다.
- `results/qa/closed_form_audit.json`: 수치 비교와 반올림 일치 검증 결과입니다.

유한 임계값에서 두 PRI 차이의 최대 절대 잔차는 4.45 × 10⁻¹⁶ 미만입니다.
새 경계 관련 검사 8개와 기존 검사 4개, 총 12개 검사가 통과했습니다.
무작위 유효 입력 1,000개에서도 경계 전·2018년 절단·2024년 절단·임계값 없음의
모든 경우를 포함하여 독립적인 수치해와 비교했습니다.

```bash
python scripts/build_restricted_bounds.py
python scripts/audit_closed_form.py
python -m unittest discover -s tests -v
# 다른 집계·그림까지 포함한 전체 재현
python reproduce.py
```

원고에 인용된 약 28%, 두 배 이상 등의 설명과 표의 반올림 수치를 고칠 필요는
없습니다. 기계판독용 CSV에는 닫힌형으로 구한 더 정밀한 값을 반영했습니다.
