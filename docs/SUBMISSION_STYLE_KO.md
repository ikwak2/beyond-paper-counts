# 첨부 예시 논문을 참고한 공개자료 설명

확인한 첨부 PDF:

- s13688-024-00451-8: 자료 접근 문장을 짧게 쓰고 Zenodo 데이터셋을 참고문헌 75번으로 인용합니다. DOI: https://doi.org/10.1140/epjds/s13688-024-00451-8 .
- s13688-025-00537-x: 원자료 접근 경로와 분석 코드 GitHub를 안내합니다. 실제 저장소 README에 원자료·버전·처리 방법을 자세히 설명하며 원본 전체를 모두 포함한다고 주장하지 않습니다. DOI: https://doi.org/10.1140/epjds/s13688-025-00537-x . 코드 저장소: https://github.com/0emerald/GB-Hyperlinks_N-S-Divide .

두 예시의 공통 방향은 논문에서는 접근 방법을 짧게 안내하고, 구현·출처 설명은 저장소에 두는 것입니다. README는 실행 명령과 주요 파일 위치로 정리했고, 자세한 내용은 DATA_AVAILABILITY.md, DATA_DICTIONARY.md, REPRODUCIBILITY.md로 연결했습니다.

다만 출판된 논문의 구성이나 인라인 URL을 그대로 복사하지는 않았습니다. 현재 EPJ Data Science 지침은 웹 URL을 번호가 있는 참고문헌으로 연결하도록 안내합니다. 최신 지침: https://link.springer.com/journal/13688/submission-guidelines/regular-article .

교수님 원고와 분석 수치는 이 저장소 수정에서 변경하지 않았습니다. 원고 Availability의 실제 DOI 반영과 공개 입력 범위에 맞춘 표현 수정은 실제 게시 후 처리할 사항입니다.
